# Predictive Analytics Hotel Booking Cancellations 

Analyzed booking behavior to identify the key drivers affecting revenue generation and booking cancellations. The project focused on transforming raw booking data into actionable business insights using statistical analysis, predictive modeling, and data visualization.
* **Dataset Size:**  119,390 hotel booking records
* **Industry:** Hospitality / Hotel Operations 
* **Variables:** 32 booking-related variables 
* **Link:** https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand
