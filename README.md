# Predictive Analytics Hotel Booking Cancellations 

Analyzed booking behavior to identify the key drivers affecting revenue generation and booking cancellations. The project focused on transforming raw booking data into actionable business insights using statistical analysis, predictive modeling, and data visualization.
* **Dataset Size:**  119,390 hotel booking records
* **Industry:** Hospitality / Hotel Operations 
* **Variables:** 32 booking-related variables 
* **Link:** https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand 

# Objectives
Hotels face significant revenue loss due to booking cancellations, no-shows, and inefficient pricing strategies. This project aimed to:
* Identify the main factors influencing booking cancellations
* Analyze revenue-driving customer behaviors and booking patterns
* Uncover actionable operational improvements
* Support data-driven pricing and booking strategies to maximize revenue

# Data Preparation
Performed data cleaning and preprocessing to improve dataset quality and analysis accuracy.
* Handled missing values and NULL records
* Standardized inconsistent country codes
* Corrected invalid negative ADR values
* Replaced undefined booking categories
* Created business metrics for analysis
